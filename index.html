Objetivo

Aprender creando sitios web utiles

Este proyecto reune conceptos basicos de desarrollo web y los organiza en una pagina moderna, responsiva e interactiva. La idea es practicar estructura HTML, estilos CSS y pequenos efectos con jQuery.

Temas principales

01

HTML5

Uso correcto de etiquetas, encabezados, enlaces, listas, secciones y contenido semantico.

02

CSS3

Colores, espaciado, tarjetas, menus, efectos hover y diseno adaptable para celulares.

03

jQuery

Animaciones sencillas, eventos del mouse y cambios dinamicos en los elementos.

Tecnologia actual

Inteligencia artificial

La inteligencia artificial esta transformando la educacion, la medicina, la programacion, la seguridad y el trabajo digital. Aprender a usarla con criterio ayuda a crear mejores soluciones para personas y empresas.

La IA no reemplaza el aprendizaje

La IA puede ayudar a investigar, corregir errores, generar ideas y automatizar tareas, pero el criterio humano sigue siendo necesario para decidir, revisar y mejorar.

Practica

Ruta de aprendizaje

1

Crear la estructura base con HTML.

2

Dar estilo con CSS y revisar en celular.

3

Agregar interactividad con JavaScript.

4

Subir cambios a GitHub y publicar con Pages.

Resultado

Proyecto final sugerido

Construir una pagina personal que muestre datos del estudiante, temas aprendidos, ejemplos de codigo y una seccion de contacto. Este repositorio puede crecer hasta convertirse en un portafolio.
