# Hello Git

Proyecto web educativo creado para practicar Git, GitHub, HTML, CSS y jQuery.

## Contenido

- Pagina principal responsiva.
- Menu de navegacion interna.
- Seccion de temas: HTML5, CSS3 y jQuery.
- Bloque interactivo sobre inteligencia artificial.
- Ruta de aprendizaje.
- Estilos modernos con CSS.

## Tecnologias usadas

- HTML5
- CSS3
- JavaScript
- jQuery
- GitHub Pages

## Como ver el proyecto

Abre el archivo `index.html` en el navegador o publica el repositorio con GitHub Pages.
